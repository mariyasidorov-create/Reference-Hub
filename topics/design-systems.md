## Corporate Design Systems

- [Carbon Design System (IBM)](https://carbondesignsystem.com/) - IBM's open-source system with components, data viz and motion. *Free.*
- [IBM Design Language](https://www.ibm.com/design/language/) - IBM's brand and product design language, including animation. *Free.*
- [Fluent 2 (Microsoft)](https://fluent2.microsoft.design/) - Microsoft's design system for web, Windows, iOS and Android. *Free.*
- [Polaris (Shopify)](https://polaris-react.shopify.com/) - Shopify admin design system: components, content and patterns. *Free.*
- [Lightning Design System (Salesforce)](https://www.lightningdesignsystem.com/) - Salesforce enterprise design system. *Free.*
- [Atlassian Design System](https://atlassian.design/) - Jira and Confluence foundations, components and content. *Free.*
- [Spectrum (Adobe)](https://spectrum.adobe.com/) - Adobe's design system across Creative Cloud. *Free.*
- [Primer (GitHub)](https://primer.style/) - GitHub's design system with Figma and React. *Free.*
- [Gestalt (Pinterest)](https://gestalt.pinterest.systems/) - Pinterest's design system. *Free.*
- [eBay Playbook](https://playbook.ebay.com/) - eBay's design system and guidelines. *Free.*
- [Base Web (Uber)](https://baseweb.design/) - Uber's React component system. *Free.*
- [Cloudscape (AWS)](https://cloudscape.design/) - AWS console design system, open source. *Free.*
- [Ant Design](https://ant.design/) - Enterprise React design system from Ant Group. *Free.*
- [GOV.UK Design System](https://design-system.service.gov.uk/) - Accessible public-service patterns from the UK government. *Free.*
- [Decathlon Design System](https://www.decathlon.design/) - Decathlon's Vitamin design system. *Free.*

## Motion in Design Systems

- [Material 3: Motion](https://m3.material.io/styles/motion/overview) - Easing, duration and transition patterns from Google. *Free.*
- [Apple HIG: Motion](https://developer.apple.com/design/human-interface-guidelines/motion) - Apple's guidance on purposeful animation. *Free.*
- [Carbon: Motion](https://carbondesignsystem.com/elements/motion/overview/) - IBM's productive and expressive motion, with easing tokens. *Free.*
- [IBM Design Language: Animation](https://www.ibm.com/design/language/animation/overview/) - IBM's brand-level animation principles. *Free.*
- [Fluent 2: Motion](https://fluent2.microsoft.design/motion) - Microsoft's motion principles and curves. *Free.*
- [Spectrum: Motion](https://spectrum.adobe.com/page/motion/) - Adobe's motion tokens and principles. *Free.*
- [Atlassian: Motion](https://atlassian.design/foundations/motion) - Atlassian's motion foundations. *Free.*

## Tools, Books and Directories

- [zeroheight](https://zeroheight.com/) - Documentation platform for design systems; also runs the Design System Awards. *Freemium.*
- [Design Systems Repo](https://designsystemsrepo.com/design-systems/) - Directory of public design systems. *Free.*
- [DesignSystems.com (Figma)](https://www.designsystems.com/) - Figma's articles on building design systems. *Free.*
- [Redesigning Design Systems](https://redesigningdesign.systems/) - Process guide to building components. *Free.*
- [Figma best practices: Branching](https://www.figma.com/best-practices/branching-in-figma/when-to-consider/) - When and how to branch a design system library. *Free.*
- [How Spotify's Design System Goes Beyond Platforms (Figma blog)](https://www.figma.com/blog/creating-coherence-how-spotifys-design-system-goes-beyond-platforms/) - Spotify's Encore system explained. *Free.*
- [Design at Uber](https://www.uber.design/) - Uber's design team site with case studies, including the 2018 rebrand. *Free.*
- [MUI](https://mui.com/) - React components based on Material Design. *Freemium.*
- [Untitled UI](https://www.untitledui.com/) - Large Figma UI kit and design system. *Freemium.*
