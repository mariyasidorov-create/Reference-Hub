## Corporate Design Systems

- [Carbon Design System (IBM)](https://carbondesignsystem.com/) - IBM's open-source system with components, data viz and motion. *Free.*
- [IBM Design Language](https://www.ibm.com/design/language/) - IBM's brand and product design language, including animation. *Free.*
- [Fluent 2 (Microsoft)](https://fluent2.microsoft.design/) - Microsoft's design system for web, Windows, iOS and Android. *Free.*
- [Polaris (Shopify)](https://polaris-react.shopify.com/) - Shopify admin design system: components, content and patterns. *Free.*
- [Lightning Design System (Salesforce)](https://www.lightningdesignsystem.com/) - Salesforce enterprise design system. *Free.*
- [Atlassian Design System](https://atlassian.design/) - Jira and Confluence foundations, components and content. *Free.*
- [Spectrum (Adobe)](https://spectrum.adobe.com/) - Adobe's design system across Creative Cloud. *Free.*
- [Primer (GitHub)](https://primer.style/) - GitHub's design system with Figma and React. *Free.*
- [Gestalt (Pinterest)](https://gestalt.pinterest.systems/) - Pinterest's design system. *Free.*
- [eBay Playbook](https://playbook.ebay.com/) - eBay's design system and guidelines. *Free.*
- [Base Web (Uber)](https://baseweb.design/) - Uber's React component system. *Free.*
- [Cloudscape (AWS)](https://cloudscape.design/) - AWS console design system, open source. *Free.*
- [Ant Design](https://ant.design/) - Enterprise React design system from Ant Group. *Free.*
- [GOV.UK Design System](https://design-system.service.gov.uk/) - Accessible public-service patterns from the UK government. *Free.*
- [Decathlon Design System](https://www.decathlon.design/) - Decathlon's Vitamin design system. *Free.*

- [IBM Design Language: Animation](https://www.ibm.com/design/language/animation/overview/) - IBM's brand-level animation principles. *Free.*
