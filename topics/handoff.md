## Handoff

- [Figma Dev Mode](https://www.figma.com/dev-mode/) - Inspect, annotate and hand off designs. *Paid.*
- [Figma Code Connect](https://www.figma.com/developers/code-connect) - Link Figma components to code in Dev Mode. *Free.*
- [Automated UI handoff (Figma)](https://www.figma.com/resource-library/automated-ui-handoff/) - How to automate design-to-development handoff. *Free.*

## Platform Guidelines

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) - Source of truth for iOS, iPadOS, macOS, watchOS and visionOS handoff. *Free.*
- [Android Design (Google)](https://developer.android.com/design) - Android UI design guidance, layouts and adaptive apps. *Free.*
- [Flutter: Building user interfaces](https://docs.flutter.dev/ui) - Official Flutter docs on widgets, layout and adaptive design. *Free.*
