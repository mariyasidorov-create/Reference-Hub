## Handoff

- [Figma Dev Mode](https://www.figma.com/dev-mode/) - Inspect, annotate and hand off designs. *Paid.*
- [Figma Code Connect](https://www.figma.com/developers/code-connect) - Link Figma components to code in Dev Mode. *Free.*
- [Automated UI handoff (Figma)](https://www.figma.com/resource-library/automated-ui-handoff/) - How to automate design-to-development handoff. *Free.*
- [Как передавать макеты в разработку [How to hand off designs to developers] (Habr)](https://habr.com/ru/articles/689434/) - Russian guide to design handoff. *Free.*

## Platform Guidelines

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) - Source of truth for iOS, iPadOS, macOS, watchOS and visionOS handoff. *Free.*
- [Android Design (Google)](https://developer.android.com/design) - Android UI design guidance, layouts and adaptive apps. *Free.*
- [Flutter: Building user interfaces](https://docs.flutter.dev/ui) - Official Flutter docs on widgets, layout and adaptive design. *Free.*
- [Apple HIG — Right to left](https://developer.apple.com/design/human-interface-guidelines/right-to-left) - Apple's rules for RTL layouts and icons. *Free.*
- [Android: Support different languages and RTL](https://developer.android.com/training/basics/supporting-devices/languages) - Android localisation and RTL support. *Free.*
- [Material Design — Bidirectionality](https://m2.material.io/design/usability/bidirectionality.html) - Mirroring rules for RTL in Material. *Free.*
- [Flutter: Internationalization](https://docs.flutter.dev/ui/internationalization) - Localisation and RTL in Flutter. *Free.*
- [Flutter: Adaptive and responsive design](https://docs.flutter.dev/ui/adaptive-responsive) - Breakpoints, navigation and input across devices. *Free.*
- [Flutter: Cupertino widgets](https://docs.flutter.dev/ui/design/cupertino) - iOS-style widgets in Flutter. *Free.*
- [Material 3 in Compose](https://developer.android.com/develop/ui/compose/designsystems/material3) - Theming Material 3 in Jetpack Compose. *Free.*

## Web

- [MDN — CSS logical properties](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_logical_properties_and_values) - Inline and block properties that mirror for RTL. *Free.*
- [W3C: Structural markup and right-to-left text in HTML](https://www.w3.org/International/questions/qa-html-dir) - How to use dir in HTML. *Free.*
- [web.dev: Learn Responsive Design](https://web.dev/learn/design) - Google's free course on responsive design. *Free.*

## Agent Skills

- [SwiftUI Agent Skill (Paul Hudson)](https://github.com/twostraws/SwiftUI-Agent-Skill) - Agent skill for writing correct SwiftUI. *Free.*
- [Claude Code Apple Skills](https://github.com/rshankras/claude-code-apple-skills) - Skills for iOS, design and Apple platforms. *Free.*
- [Flutter RTL Audit](https://github.com/TaheBenSaid/flutter-rtl-audit) - Agent skill that audits Flutter apps for RTL problems. *Free.*
- [Front-End Checklist](https://github.com/thedaviddias/Front-End-Checklist) - Front-end checklist, also published as agent skills. *Free.*

## Platform Guidelines as Skills

- [Platform Design Skills (ehmo)](https://github.com/ehmo/platform-design-skills) - Apple HIG, Material 3 and WCAG 2.2 rules as agent skills for checking designs before handoff. *Free.*
