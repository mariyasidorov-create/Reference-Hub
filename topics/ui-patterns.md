## Pattern Libraries and Real Products

- [Mobbin](https://mobbin.com/) - Screens, flows and website sections from real products. *MCP server.*
- [Page Flows](https://pageflows.com/) - Full recorded flows: onboarding, checkout, upgrade, cancellation. *Login.*
- [Refero](https://refero.design/) - Web and iOS screens and flows, searchable by pattern. *Partly paid.*
- [UI Patterns](https://ui-patterns.com/) - Named UI patterns, including persuasive patterns. *Free.*
- [Screens Design](https://screensdesign.com/) - Mobile screens, paywalls and app store screenshots. *Free.*
- [SaaSFrame](https://www.saasframe.io/) - SaaS patterns: pricing, onboarding, dashboards. *Partly paid.*
- [Nicelydone](https://nicelydone.club/) - Flows from SaaS products. *Partly paid.*
- [UX Archive](https://uxarchive.com/) - Mobile flows organised by task. *Free.*
- [Paywall Screens](https://www.paywallscreens.com/) - Gallery of mobile app paywalls. *Free.*
- [SaaS Interface](https://saasinterface.com) - SaaS product screens organised by pattern. *Free.*
- [Appshot Gallery](https://appshot.gallery) - App Store screenshots for inspiration. *Free.*

## More Patterns

- [Welie.com Interaction Design Pattern Library](http://www.welie.com/patterns/) - Classic pattern library. *Free.*
- [UI design principles (Figma)](https://www.figma.com/resource-library/ui-design-principles/) - Core UI principles with examples. *Free.*
- [Azbuka UI (UI ABC)](https://azbuka.uiuxlove.ru/) - Interactive guide to UI elements with live examples, code names and a test, by Kris Anfalova (in Russian). *Free.*
- [UI Playbook](https://uiplaybook.dev/) - Component-by-component guide to building UI elements. *Free.*
- [Empty States: More Work Than You Think (Shopify UX)](https://medium.com/shopify-ux/empty-states-more-like-you-have-no-idea-how-much-work-goes-into-those-states-ami) - Shopify on designing empty states. *Free.*
