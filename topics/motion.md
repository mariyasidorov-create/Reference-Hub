## Micro-interactions and Motion References

- [Design Spells](https://designspells.com/) - Easter eggs and delightful details in interfaces. *Free.*
- [60fps](https://60fps.design/) - More than 2,000 iOS interactions with SwiftUI code. *Free, MCP.*
- [Spotted in Prod](https://www.spottedinprod.com/) - Videos of iOS interfaces with frame-by-frame scrubbing. *Free.*
- [Ripplix](https://www.ripplix.com/) - Library of UI animations. *Free.*
- [Capptivate](https://github.com/capptivateco/capptivate) - Archive of classic iOS animations. *Free.*
- [GSAP](https://gsap.com/) - Web animation library with buildable examples. *Free.*
- [Eyecandy](https://eyecannndy.com/) - Visual dictionary of video and film techniques. *Free.*
- [Uiverse](https://uiverse.io/) - Open-source UI elements with hover effects. *Free.*
- [CodePen](https://codepen.io/) - Interaction demos with code. *Free.*
- [Aceternity UI](https://ui.aceternity.com/) - Animated components for Tailwind and Next.js. *Partly paid.*
- [MicroKit](https://microkit.co) - Copy-paste micro-interactions in React and CSS. *Free.*
- [Kinetics](https://kinetics.colorion.co) - Spring animation examples in CSS and React Spring. *Free.*
- [Text Effects](https://text-effects.colorion.co) - 123 text effects in CSS. *Free.*
- [Gradient Buttons](https://gradientbuttons.colorion.co) - Buttons with CSS gradients. *Free.*
- [Circle Loaders](https://circleloaders.dominikakissi.com) - 24 monochrome 'agent is thinking' loaders. *Free.*
- [liquid-glass](https://glass.samasante.com) - Liquid glass effect over the live DOM. *Free.*
- [Motion](https://motion.dev) - Animation library for JavaScript and React, formerly Framer Motion. *Free.*
- [Anime.js](https://animejs.com) - JavaScript animation engine with demos. *Free.*
- [Zajno Motion](https://motion.zajno.com) - Motion design principles as interactive examples. *Free.*

## Motion Tools

- [Jitter](https://jitter.video) - Motion design in the browser. *Freemium.*
- [LottieFiles](https://lottiefiles.com) - Library and editor for Lottie animations. *Freemium.*
- [Bloop](https://bloop.wtf/templates) - Template-based motion animation for images. *Free.*
- [Paper Animation](https://paperanimation.ai) - Match-cut effect. *Freemium.*
- [Ink overlays](https://arnoldfrancisca.com/tools/ink) - Animated handwritten overlays. *Free.*
- [3D GIF Maker](https://3dgifmaker.com) - 3D GIF from a flat image. *Free.*
- [Dasca](https://app.dasca.studio) - Real-time image effects. *Free.*
- [WigglyPaint](https://wigglypaint.com) - Animated wiggly doodles. *Free.*
- [glimm](https://glimm.dev/) - Shader-driven page transitions for React and Next.js, about 11 KB. Found via Sidebar. *Free.*
