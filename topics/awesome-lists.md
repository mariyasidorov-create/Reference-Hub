## Claude Skills

- [anthropics/skills](https://github.com/anthropics/skills) - Official Anthropic skills and format examples. *Free.*
- [skills.sh](https://skills.sh) - Searchable catalogue of agent skills. *Free.*
- [awesome-claude-skills (ComposioHQ)](https://github.com/ComposioHQ/awesome-claude-skills) - Large community list of Claude skills. *Free.*
- [awesome-claude-skills (travisvn)](https://github.com/travisvn/awesome-claude-skills) - Curated list of Claude skills. *Free.*
- [awesome-claude-skills (VoltAgent)](https://github.com/VoltAgent/awesome-claude-skills) - Claude skills organised by category. *Free.*
- [awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code) - Skills, commands, hooks and plugins for Claude Code. *Free.*
- [Humanizer (blader)](https://github.com/blader/humanizer) - Removes AI-writing patterns, based on Wikipedia's guide to spotting AI text. *Free.*
- [Matt Pocock's skills (Grill Me)](https://github.com/mattpocock/skills) - Skills that question your plan before building. *Free.*
- [Superpowers (obra)](https://github.com/obra/superpowers) - Battle-tested engineering workflows as one skills pack. *Free.*
- [Impeccable (Paul Bakaus)](https://github.com/pbakaus/impeccable) - Design skill that makes vibe-coded UI look less generic. Recommended by Nelson (nels_ysng). *Free.*
- [Firecrawl plugin for Claude](https://github.com/firecrawl/firecrawl-claude-plugin) - Reliable web scraping for Claude. *Free + paid API.*
- [Claude Code Router](https://github.com/musistudio/claude-code-router) - Route Claude Code to other model providers. *Free.*
- [Open Design (nexu-io)](https://github.com/nexu-io/open-design) - Open-source, local-first alternative to Claude Design: hundreds of skills and DESIGN.md systems for Linear, Stripe, Apple and more. Shown by Joshua Stevenson. *Free.*
- [Claude-Mem](https://github.com/thedotmack/claude-mem) - Memory across Claude Code sessions. Shown by Nelson (nels_ysng). *Free.*
- [Vercel Skills (find-skills)](https://github.com/vercel-labs/skills) - npx skills installer; find-skills searches and installs skills for a task. *Free.*
- [Platform Design Skills (ehmo)](https://github.com/ehmo/platform-design-skills) - 300+ rules from Apple HIG, Material 3 and WCAG 2.2 for building and auditing apps. Close match to the Apple design skill shown by Nelson. *Free.*
- [Apple HIG Skills (Raintree)](https://github.com/raintree-technology/apple-hig-skills) - Apple Human Interface Guidelines split into installable skills. *Free.*
- [Everything Claude Code (affaan-m)](https://github.com/affaan-m/everything-claude-code) - Configs for token optimisation, memory, verification loops and subagents. *Free.*
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - Searchable design-intelligence skill: UI styles, palettes, font pairings and UX rules per stack. *Free, open source.*
- [Emil Kowalski's Skills](https://github.com/emilkowalski/skills) - Design-engineering skills from the animations.dev author: emil-design-eng, animate, review and improve animations. *Free, open source.*
- [Oil UI](https://github.com/oil-oil/oil-ui) - Explores several distinct design directions, compares them side by side, then refines against screenshots. *Free, open source.*
- [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md) - DESIGN.md files modelled on Stripe, Linear, Vercel and more: drop one in so an agent starts from a real visual system. *Free, open source.*
- [Hallmark](https://github.com/Nutlope/hallmark) - Anti-AI-slop design skill: picks a page structure and theme per brief, audits pages, extracts a design.md from references. *Free, open source.*
- [Marketing Skills (Corey Haines)](https://github.com/coreyhaines31/marketingskills) - CRO, copywriting, SEO, analytics and growth skills for coding agents. *Free, open source.*
- [Cloudflare security-audit skill](https://github.com/cloudflare/security-audit-skill) - Official Cloudflare skill: multi-phase security audit of a codebase with independently verified findings. Useful for anything vibe-coded. *Free, open source.*
- [/awwwards and /jury (juliobsz)](https://github.com/juliobsz/skills) - /awwwards builds award-calibre sites from one line; /jury scores any site the way an Awwwards jury would. *Free, open source.*
- [Impeccable — site and docs](https://impeccable.style/) - Docs, before/after cases and downloads for Paul Bakaus's design skill (23 commands, anti-pattern detectors). *Free, open source.*
