## Claude Skills

- [anthropics/skills](https://github.com/anthropics/skills) - Official Anthropic skills and format examples. *Free.*
- [skills.sh](https://skills.sh) - Searchable catalogue of agent skills. *Free.*
- [awesome-claude-skills (ComposioHQ)](https://github.com/ComposioHQ/awesome-claude-skills) - Large community list of Claude skills. *Free.*
- [awesome-claude-skills (travisvn)](https://github.com/travisvn/awesome-claude-skills) - Curated list of Claude skills. *Free.*
- [awesome-claude-skills (VoltAgent)](https://github.com/VoltAgent/awesome-claude-skills) - Claude skills organised by category. *Free.*
- [awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code) - Skills, commands, hooks and plugins for Claude Code. *Free.*
- [Humanizer (blader)](https://github.com/blader/humanizer) - Removes AI-writing patterns, based on Wikipedia's guide to spotting AI text. *Free.*
- [Matt Pocock's skills (Grill Me)](https://github.com/mattpocock/skills) - Skills that question your plan before building. *Free.*
- [Superpowers (obra)](https://github.com/obra/superpowers) - Battle-tested engineering workflows as one skills pack. *Free.*
- [Impeccable (Paul Bakaus)](https://github.com/pbakaus/impeccable) - Design skill that makes vibe-coded UI look less generic. Recommended by Nelson (nels_ysng). *Free.*
- [Firecrawl plugin for Claude](https://github.com/firecrawl/firecrawl-claude-plugin) - Reliable web scraping for Claude. *Free + paid API.*
- [Claude Code Router](https://github.com/musistudio/claude-code-router) - Route Claude Code to other model providers. *Free.*

## Design Lists on GitHub

- [awesome-design-systems (alexpate)](https://github.com/alexpate/awesome-design-systems) - Company design systems with links. *Free.*
- [awesome-design-systems (klaufel)](https://github.com/klaufel/awesome-design-systems) - Articles, tools and examples of design systems. *Free.*
- [awesome-design](https://github.com/gztchan/awesome-design) - General list of design resources. *Free.*
- [Awesome Design Tools](https://github.com/goabstract/Awesome-Design-Tools) - Tools and plugins for designers. *Free.*
- [Design Resources for Developers](https://github.com/bradtraversy/design-resources-for-developers) - Fonts, icons, photos, colour and UI kits. *Free.*
- [motion-ui-design](https://github.com/fliptheweb/motion-ui-design) - Resources on motion design and UI animation. *Free.*
- [awesome-ui-component-library](https://github.com/anubhavsrivastava/awesome-ui-component-library) - Component libraries by framework. *Free.*
- [awesome-react-components](https://github.com/brillout/awesome-react-components) - React components and libraries. *Free.*
- [awesome-creative-coding](https://github.com/terkelg/awesome-creative-coding) - Generative art, shaders and WebGL. *Free.*
- [awesome-icons](https://github.com/notlmn/awesome-icons) - Icon sets. *Free.*
- [awesome-css](https://github.com/awesome-css-group/awesome-css) - CSS techniques and tools. *Free.*
- [awesome-stock-resources](https://github.com/neutraltone/awesome-stock-resources) - Free stock photos, videos and illustrations. *Free.*
- [free-for-dev](https://github.com/ripienaar/free-for-dev) - Free tiers of services for projects. *Free.*
- [sindresorhus/awesome](https://github.com/sindresorhus/awesome) - The list of awesome lists, with a Design section. *Free.*
- [awesome-a11y](https://github.com/brunopulis/awesome-a11y) - Accessibility resources. *Free.*
- [awesome-web-design](https://github.com/nicolesaidy/awesome-web-design) - Books, tools and inspiration for web design (last updated 2023). *Free.*
- [Public APIs](https://github.com/public-apis/public-apis) - Thousands of free APIs by category, handy for prototypes. *Free.*
