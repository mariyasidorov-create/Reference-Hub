## Guidelines

- [Understanding WCAG 2.2 (GOV.UK Service Manual)](https://www.gov.uk/service-manual/helping-people-to-use-your-service/understanding-wcag) - Plain-language guide to WCAG 2.2. *Free.*
- [ARIA Authoring Practices: Patterns (W3C)](https://www.w3.org/WAI/ARIA/apg/patterns/) - Accessible patterns for common components. *Free.*
- [Accessibility Not-Checklist (Intopia)](https://not-checklist.intopia.digital/) - WCAG by role and task, not as a checklist. *Free.*
- [APCA contrast (Myndex)](https://apcacontrast.com/) - Contrast calculator for the APCA method. *Free.*
- [IxDF: Accessibility](https://ixdf.org/literature/topics/accessibility) - Articles on accessible design. *Free.*
- [APCA (Myndex)](http://www.myndex.com/APCA/) - Original APCA contrast calculator by its author. *Free.*
- [Практики доступности интерфейсов — МТС [MTS interface accessibility practices]](https://a11y.mts.ru/) - Russian telecom's public accessibility guide. *Free.*

## Figma Plugins

- [Stark](https://www.figma.com/community/plugin/732603254453395948/stark-contrast-accessibility-tools) - Contrast and accessibility checks in Figma. *Freemium.*
- [Contrast](https://www.figma.com/community/plugin/748533339900865323) - Quick WCAG contrast checks. *Free.*
- [Contrast Grid](https://www.figma.com/community/plugin/993414361395505148/contrast-grid) - Contrast matrix for a whole palette. *Free.*
- [Adee Comprehensive Accessibility Tool](https://www.figma.com/community/plugin/931280467863251825) - Contrast, text size and colour-blindness simulation. *Free.*

## Mobile Testing: iOS and Android

- [Accessibility Inspector (Apple)](https://developer.apple.com/documentation/accessibility/accessibility-inspector) - Xcode tool to inspect labels, traits and hierarchy on a simulator or device and run an automatic audit. *Free.*
- [Performing accessibility testing for your app (Apple)](https://developer.apple.com/documentation/accessibility/performing-accessibility-testing-for-your-app) - Apple's guide to manual and automated testing: VoiceOver, Dynamic Type, Accessibility Inspector and UI-test audits. *Free.*
- [Human Interface Guidelines: Accessibility (Apple)](https://developer.apple.com/design/human-interface-guidelines/accessibility) - Design rules for iOS: text size, contrast, VoiceOver, motion and hit targets. *Free.*
- [Turn on and practice VoiceOver on iPhone](https://support.apple.com/guide/iphone/turn-on-and-practice-voiceover-iph3e2e415f/ios) - Official VoiceOver gestures guide, the first step of any manual screen-reader test. *Free.*
- [Accessibility Scanner (Android)](https://play.google.com/store/apps/details?id=com.google.android.apps.accessibility.auditor) - Google's app that scans any screen and flags small touch targets, low contrast and missing labels. *Free.*
- [Get started with Accessibility Scanner](https://support.google.com/accessibility/android/answer/6376570) - How to install, run and read the results of Accessibility Scanner. *Free.*
- [Test your app's accessibility (Android Developers)](https://developer.android.com/guide/topics/ui/accessibility/testing) - Manual, analysis and automated testing on Android: TalkBack, Switch Access, Scanner, Espresso checks. *Free.*
- [Accessibility testing in Jetpack Compose](https://developer.android.com/develop/ui/compose/accessibility/testing) - Semantics-based tests and automated checks for Compose UIs. *Free.*
- [Accessibility Test Framework for Android (Google)](https://github.com/google/Accessibility-Test-Framework-for-Android) - The open-source rule engine behind Accessibility Scanner and Espresso accessibility checks. *Free, open source.*
- [Get started with TalkBack](https://support.google.com/accessibility/android/answer/6283677) - Official TalkBack guide for manual screen-reader testing on Android. *Free.*
- [Material Design 3: Accessibility](https://m3.material.io/foundations/designing/overview) - Material's accessibility foundations: structure, flow, element sizing and colour for Android apps. *Free.*
