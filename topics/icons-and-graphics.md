## Icons, Illustrations and Graphics

- [Lucide](https://lucide.dev) - Open-source SVG icons. *Free.*
- [Iconly](https://iconly.pro) - More than 40,000 icons, including animated ones. *Freemium.*
- [Koboyo](https://koboyo.com/icons) - 292,000 hand-drawn icons. *Free.*
- [Kitbitz](https://kitbitz.art) - More than 2,000 hand-drawn illustrations. *Free.*
- [Inkword](https://inkword.app) - Generator of minimalist illustrations. *Free.*
- [PNGimg](https://pngimg.com) - PNG images with transparent backgrounds. *Free.*
- [Emoji to PNG](https://emoji.aranja.com) - Any emoji as a PNG. *Free.*
- [mmeshy](https://mmeshy.com) - Mesh gradient editor and gallery. *Free.*
- [Cutting Mat Generator](https://cutting-mat-generator.vercel.app) - Backgrounds in the style of a cutting mat. *Free.*
- [Holosticker](https://holosticker.dev) - Holographic foil effect for logos. *Free.*
- [Reicon](https://reicon.dev) - More than 2,700 open-source SVG icons. *Free.*
- [Sombra](https://sombra.design) - Gradient builder. *Free.*
- [Phosphor Icons](https://phosphoricons.com) - Flexible icon family in six weights. *Free.*
- [3dicons](https://3dicons.co) - Open-source 3D icons. *Free.*
- [Symbl](https://symbl.space) - Logo stress test: small sizes, blur, negative space, clearspace, mockups and a shareable brand book. *Free.*
- [playgrnd](https://www.playgrnd.tools/) - 52 free in-browser generators for backgrounds, patterns, posters and textures (dither, riso, op-art, marbling). Nothing uploaded; exports are yours. Some artists say certain tools imitate their styles, so check before using output commercially. *Free.*

## Icons

- [Noun Project](https://thenounproject.com/) - Millions of icons and photos. *Freemium.*
- [Material Symbols](https://fonts.google.com/icons) - Google's variable icon font. *Free.*
- [Flaticon](https://www.flaticon.com/) - Large icon library. *Freemium.*
- [Iconbuddy](https://iconbuddy.app/) - 100,000+ open-source icons. *Free.*
- [Iconoteka](https://iconoteka.com/) - Icon library in several styles. *Freemium.*
- [Iconoteka on GitHub](https://github.com/iconoteka/iconoteka) - 1,400 MIT icons in 7 weights, with MCP server and dev packages, by Oleg Turbaba. *Free.*
- [Iconoteka Figma plugin](https://www.figma.com/community/plugin/1675995752572535073/iconoteka) - The full Iconoteka library inside Figma, with restyle mode. *Free.*
- [Iconden](https://iconden.com/) - Community gallery of iPhone app icons, with redesign history. Found via Sidebar. *Free.*
