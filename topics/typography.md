## Free Cyrillic Typefaces (OFL)

- [Golos Text](https://fonts.google.com/specimen/Golos+Text) - Alexandra Korolkova, Vitaly Kuzmin (Paratype). UI sans built for clear reading at small sizes. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Onest](https://fonts.google.com/specimen/Onest) - Dmitri Voloshin, Andrey Kudryavtsev. Neutral grotesque for interfaces and long texts. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Manrope](https://fonts.google.com/specimen/Manrope) - Mikhail Sharanda. Modern geometric-grotesque, popular for product UI. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Inter](https://fonts.google.com/specimen/Inter) - Rasmus Andersson. The default UI sans of many design systems, variable, with Cyrillic. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Unbounded](https://fonts.google.com/specimen/Unbounded) - NaN. Wide display face with a strong Cyrillic. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) - Mike Abbink, Bold Monday. IBM's corporate sans with full Cyrillic. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Fira Sans](https://fonts.google.com/specimen/Fira+Sans) - Carrois Apostrophe. Humanist sans from Mozilla, good for long reading. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [PT Sans](https://fonts.google.com/specimen/PT+Sans) - ParaType. Public Types of Russia, one of the first free Cyrillic families. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [PT Serif](https://fonts.google.com/specimen/PT+Serif) - ParaType. Serif companion to PT Sans. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Literata](https://fonts.google.com/specimen/Literata) - TypeTogether. Book serif made for Google Play Books, variable. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4) - Frank Grießhammer (Adobe). Text serif with optical sizes. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) - JetBrains. Monospace for code with ligatures. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Geologica](https://fonts.google.com/specimen/Geologica) - Monokrom. Variable sans with a 'sharpness' axis from Monokrom (Oslo). Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Spectral](https://fonts.google.com/specimen/Spectral) - Production Type. Screen-first text serif. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Cormorant](https://fonts.google.com/specimen/Cormorant) - Christian Thalmann. Garamond-style display serif with full Cyrillic. Licence: SIL Open Font License 1.1. *Free (OFL).*
- [Roboto Flex](https://fonts.google.com/specimen/Roboto+Flex) - Font Bureau, with Cyrillic by Ilya Ruderman and Yury Ostromentsky. Highly variable Roboto. Licence: SIL Open Font License 1.1. *Free (OFL).*
