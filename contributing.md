# Contribution Guidelines

Thank you for suggesting a reference. Please make sure your pull request meets these rules.

- Add one link per pull request, and say in the description why it belongs here.
- Check that the link opens and is not behind a paywall you cannot describe honestly.
- Put the link in the most specific topic file and section. Create a new section only if three or more links need it.
- Use the format `- [Name](https://link) - Description. *Access.*`
  - Keep the original name. If it is not in English, add an English translation in brackets, for example `MUDE — Museu do Design (Design Museum, Lisbon)`.
  - Write the description in English, start with a capital letter and end with a full stop.
  - State access honestly: free, free with sign-up, freemium, paid, view only, mixed licences.
- Legal sources only. No pirated PDFs of books that are sold. Publisher previews, library loans and public domain scans are welcome.
- Prefer English-language sources. Use another language when the source is about that region or no English edition exists.
- Prefer precise, specialised books and well-designed editions over general encyclopedias.
- No AI-generated image galleries in the photo and archive sections.
- If you add a new topic file, add YAML front matter (`title`, `tags`, `entries`), a Related line linking to at least two existing topics, a link back to the index, and a node in [knowledge-map.md](knowledge-map.md).

By contributing you agree to release your contribution under [CC0](LICENSE).
